# Akasha Plugins

The repository contains executable extensions for Akasha. Its catalog includes agent tools and channel bridges, with support for rich output in the desktop and terminal interfaces.

## Package and review a plugin

Use the package format and manifest described in the repository README. Check the trust catalog for review metadata, hashes, and MCP expectations, then follow the test instructions before regenerating the catalog.
